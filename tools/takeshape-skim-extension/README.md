# Away Lands TakeShape Editor Styling

This Chrome extension makes the TakeShape story editor easier to scan. It only runs on TakeShape Story create and edit pages. It does not change saved content or the published Away Lands website.

## Install in Chrome

1. Open `chrome://extensions/`.
2. Turn on **Developer mode** in the upper-right corner.
3. Click **Load unpacked**.
4. Choose this entire `takeshape-skim-extension` folder.
5. Reload the open TakeShape story editor tab.

When these files are updated later, open `chrome://extensions/`, find **Away Lands TakeShape Editor Styling**, click its refresh icon, and reload TakeShape.
